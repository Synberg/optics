В данной ветке представлены методы обработки изображений, использующие темнопольную микроскопию и фазовый контраст. Эти методы позволяют выделять еле заметные объекты, такие как бактерии в жидкости, за счет преобразования Фурье и модификации фазовых компонентов изображения. Программа демонстрирует применение данных методов к исходному изображению, визуализируя результаты их работы.
