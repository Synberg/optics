Данная ветка посвящена моделированию линзы и трассировке лучей, проходящих через нее. Реализованы расчеты формы линзы, построение оптической системы и визуализация прохождения лучей через линзу с учетом преломления. Визуализация выполняется на основе JavaFX, позволяя наблюдать за изменением траекторий лучей при их взаимодействии с линзой.
