В данной ветке представлена программа на языке программирования Java, выполняющая базовые вычисления, связанные с трассировкой лучей, а также их визуализацию с использованием JavaFX. Реализованы алгоритмы определения пересечения, отражения и преломления лучей с различными объектами сцены, включая плоскость, сферу и эллипсоид. Программа позволяет наглядно исследовать поведение лучей в двухмерном пространстве и служит основой для более сложных симуляций.
